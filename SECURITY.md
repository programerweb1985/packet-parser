# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability in `packet-parser`, please report it responsibly through GitHub's **private vulnerability reporting**.

To report a vulnerability:

1. Go to the repository's **Security** tab.
2. Click **"Report a vulnerability"**.
3. Provide a clear description, affected versions, and (if possible) a proof of concept.

Alternatively, email the maintainers directly. We will respond as soon as possible and keep you updated throughout the triage and fix process.

## Supported Versions

| Version | Supported |
|---------|-----------|
| `1.0.1`   | ✅ Yes |
| `<= 1.0.0` | ❌ No (contains CVE — upgrade immediately) |

## Disclosure Process

1. Report is submitted privately.
2. Maintainers confirm and triage the issue.
3. A patch is prepared and released.
4. A GitHub Security Advisory (and CVE, if requested) is published.
5. The reporter is credited (unless they prefer to remain anonymous).

We aim to acknowledge reports within **48 hours** and provide a fix for confirmed critical issues as quickly as possible.
